Cyber Grid Command

Overview

A browser game about defending a network: patch vulnerabilities and quarantine malware before the threat meter fills.

Technologies

Game designJavaScriptCanvasPlaywright

Problem and motivation

Security awareness training is usually passive, and most people forget it quickly. The core idea of defense, choosing what to fix first with limited time and resources, is rarely felt firsthand.

Approach

Cyber Grid Command turns that idea into a turn-based board game. Players move across a network grid with a limited number of actions per turn, patching vulnerabilities and quarantining malware while a threat meter rises. The game ends in a win when the network is secured, or a loss when the threat overwhelms it.

Technical design considerations

  • Prioritization is the mechanic. Limited actions force the same trade-offs real defenders make.
  • Readable at a glance. The board shows the state of the network without explanation.
  • Tested like software. Automated play-throughs verify that win and loss paths behave correctly.

Learning goals

  • Triage under pressure. Players learn that not every issue can be fixed at once.
  • Containment matters. Quarantining threats early prevents them from spreading.
  • Approachable. No security background is needed to start playing.

Outlook

Games can make security intuition stick in a way slides cannot. Small, focused games are an inexpensive complement to formal awareness programs.
