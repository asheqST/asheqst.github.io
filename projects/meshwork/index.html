AI securityIndependent project

Meshwork

Overview

A distributed AI compute network where every node and agent carries a verifiable identity, so work only goes to parties that can prove who they are.

Technologies

Distributed systemsAgent identityZero Trust

Problem and motivation

Pooling compute across many independent machines can make AI inference cheaper and more resilient. It also raises a hard trust problem: who is running your workload, and can they be held accountable for the result?

Approach

Meshwork proposes a peer-to-peer network that routes inference tasks to suitable models, where every node and agent presents a verifiable identity built on the Agent Identity Certificates model. Each task is recorded against the identities involved, and traffic between nodes is encrypted.

Technical design considerations

  • No anonymous compute. Work is routed only to nodes that can prove their identity.
  • Accountability over blind trust. Every result can be traced to the node that produced it.
  • One identity model. The same approach governs agents calling tools and nodes running work.

Security considerations

  • Untrusted operators. Nodes are run by third parties, so identity and audit replace assumptions of good behavior.
  • Data exposure. Workloads carrying sensitive data should be routed only to nodes that meet stated requirements.
  • Sybil resistance. Tying participation to verifiable identity makes it harder to flood the network with fake nodes.

Outlook

Decentralized compute will only be usable for serious workloads if it offers the accountability of a contract. Verifiable identity is the missing layer that makes that possible.
